Try it · a FRAD node on your own machine

One command. The release arrives here, in a container.

The booth is the release: a container holding the install image, with its signatures when the build was signed, and qemu to run it. Run it, and this page finds it: the files to download, an install you can watch, then the console of the node it made, the nodes you add, and the Ceph dashboard, all right here. Nothing leaves your machine.

One terminal. Paste the line into a terminal on this machine (Linux with Docker, or Windows 11 with WSL2, with KVM; without KVM the booth still serves the downloads); the moment the booth answers, this page shows its downloads and this box offers the install. The image is about 2.4 GB and the line pulls the current one each time. Install via CDROM or via USB runs unattended in the console, a few minutes, and the node that boots from it is h1. The install and h1 take 6 GB of memory, each node you add 4 GB.

Start the boothlog in as admin, password admin (the factory login; the setup screen sets a new one) looking for a booth on this machine…

Dashboard on the virtual IP: user admin, the node's admin password

The install writes a disk once; every node boots a throwaway copy of it. h1 comes up at its banner a couple of minutes after the install: F2, the factory login admin / admin, and its setup screen proposes a cluster of its own; one press forms it. A node added later proposes joining that cluster; set its host name (2) before accepting with a. Remove node takes the node on screen away, Reset starts the session over from the installed disk, End booth ends the container; each asks twice. The disk lives with the container: a new booth installs again, and what stays on your machine is the image: docker rmi ghcr.io/chienpanglee/frad-booth.
